# NOT3S

A simple 3D notebook built with Three.js for the Polygon Build a 3D Website Workshop

## How it works

- Click on the notebook to start typing
- Your notes appear directly on the notebook pages
- Text wraps automatically when a line is full
- Create new pages and switch between them using the buttons
- The notebook can be rotated and zoomed to view it from different angles

Built with
HTML, CSS, JavaScript, Three.js.

## Assets

- 1 custom texture back cover design
- 2 main models
  - Notebook cover
  - Paper pages
- 8 torus models used as spiral binding rings
